# Product documentation

Product documentation defines what Aeria is for and the invariants implementation must preserve. It does not own implementation details.

- [`vision.md`](./vision.md) — product purpose, primary workflows, target users, and first-release experience.
- [`principles.md`](./principles.md) — non-negotiable product and data invariants.

Read both before changing user-facing workflow, project semantics, review state, source handling, or collaboration behavior.
