A desktop app for fan translations of FINAL FANTASY XIV

Aeria opens the text straight from your game install, and Angelica, its built-in AI agent, helps you translate it. You can work alone or with your language's whole community, and a game patch breaks neither your project nor the translation players already have installed.

Angelica

Angelica is the AI translation agent built into Aeria. Before she suggests anything, she reads what your project has already translated, looks up similar lines, checks how the line reads in the game's other languages, and follows your glossary and style notes, so her suggestions fit the rest of the project.

Give her one line or whole sheets. Big jobs run in the background and can be paused and resumed. You can also just talk a tricky passage over with her. A line with broken tags never gets written.

You have the final say. Every edit she suggests appears next to the current translation for you to accept or reject, and only a person can mark a line as reviewed. You connect your own model through OpenRouter or a ChatGPT subscription; Aeria works without AI too.

Most of the work on Aeria is going into Angelica right now.

Numbers, names, and highlights are filled in by the game itself through tags. You can move tags to fit your language's grammar, but Aeria won't save a line with a missing or broken tag.

Editor

Instead of raw code, the editor shows tags as readable hints like "if the character is female", and colored text appears in its color. You can copy a tag from the original with one click, and mistakes are flagged as you type. Search covers all of the game's text.

Patches

A patch doesn't break your translation. Aeria moves it to the new version of the game and flags the lines the developers changed so you can reread them. When it can't tell for sure where a translation belongs, it sets it aside for review instead of guessing. Nothing gets lost.

Packs players already have installed keep working too. Lines that changed show in the original language until the author publishes an update, and a translation is never applied to text it wasn't written for.

Working together

One person or a whole community can work on a translation. The project is an ordinary Git repository on GitHub or any other host, and Git comes with Aeria. Saving and syncing is enough for everyday work, with branches and pull requests there when you need them. Every line keeps a history of its edits.

No accounts or Aeria servers are involved.

Harmonia

Harmonia, a Dalamud plugin, shows the translation in the game. You can publish a pack to GitHub Releases right from Aeria, and players install it like this:

  1. Launch the game through XIVLauncher with Dalamud enabled.
  2. Open /xlsettings → Experimental → Custom Plugin Repositories, add this address, and save:
    https://raw.githubusercontent.com/AngelicaProject/Harmonia/main/repo.json
  3. Open /xlplugins, install Harmonia, and restart the game.
  4. Open /harmonia, press Add translation, and paste the link from the translation's author or choose a downloaded .hpk file. Restart the game once more.

A translation added from a link updates itself; changes take effect the next time you start the game. Cyrillic and other characters the game's fonts lack need Penumbra to show up in window titles and on the title screen.

Status

Aeria is at an early stage and changes quickly. For now there's only a Windows version; Linux will come later. Report bugs and ideas in GitHub Issues. Pull requests are welcome too.
