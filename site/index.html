Agents translate whole scenes

Claude Code, Codex, or Hermes Agent connect with one button in Settings. An agent gets a whole quest or cutscene in play order and sees every line with the Japanese original, the English, German, and French versions, and the project's terms, style, and character voices.

Large jobs are split among helper agents working in parallel. Everything they write shows up in the editor right away and stays in the project history.

Lines a person wrote or approved are off limits to agents.

All three tags in place in every translation

The game fills in numbers, names, and highlights through tags. Tags can move to fit the grammar of each language, but a line with a lost or broken tag is never saved, whoever wrote it.

Editor

Tags read as plain hints like "if the character is female", colored text shows in the game's colors, and search covers all of the game's text.

Terms, style, and character voices live in the project next to the translation, and people and agents work from them alike.

Game updates

When a patch lands, Aeria carries the translation over to the new version and marks the lines the developers changed. When it can't tell where a translation belongs, the translation goes to review instead of a guess.

Packs players already have keep working: changed lines show in the original language until an update comes out.

Working together

A project is a plain Git repository on GitHub or anywhere else, and Git comes with Aeria. Save and sync cover everyday work; branches and pull requests are there for bigger teams.

Every line keeps its edit history. No accounts, no servers.

Harmonia

Harmonia, a Dalamud plugin, shows the translation in the game. Aeria publishes packs to GitHub Releases, and players install them like this:

  1. Launch the game through XIVLauncher with Dalamud enabled.
  2. Open /xlsettings → Experimental → Custom Plugin Repositories, add this address, and save:
    https://raw.githubusercontent.com/AngelicaProject/Harmonia/main/repo.json
  3. Open /xlplugins, install Harmonia, and restart the game.
  4. Open /harmonia, press Add translation, and paste the link from the translation's author or choose a downloaded .hpk file. Restart the game once more.

A translation added from a link updates itself at the next game start. Cyrillic and other characters the game's fonts lack need Penumbra in window titles and on the title screen.

Development
