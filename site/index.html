A desktop app for fan translations of FINAL FANTASY XIV

Aeria is a desktop app for fan translations of FINAL FANTASY XIV. It reads the text straight from the installed game, checks the game's tags on every save, and carries a translation over to each new game version without losses. A project can be worked on by a single translator or by a whole language community.

Translating with AI agents

Aeria has no language model of its own. Translation is done by external AI agents — Claude Code, Codex, Hermes Agent, or any other agent that can run commands. They work on a project through the aeria command, which is set up in Aeria's settings.

An agent receives a whole quest or cutscene, in the order the player sees it. Each line comes with the Japanese original, the English, German, and French versions, and the project's terms, style rules, and descriptions of how each character speaks. Large amounts of work are split among several agents translating in parallel.

Every translation is checked before it is saved: a line with a damaged tag, a forbidden variant of a term, or both genders written into one word is not saved. Translations a person wrote or confirmed are never replaced by an agent. Whatever an agent writes appears in the editor at once and enters the project history like any other edit.

Numbers, names, and highlights are filled in by the game itself through tags. Tags can be moved to fit the grammar of the target language, but a line with a missing or damaged tag is not saved.

Editor

The editor shows tags as readable labels such as "if the character is female" rather than raw code, and colored text in the color the game will use. A tag from the original is copied into the translation with one click, and mistakes are marked while typing. Search covers all of the game's text.

Terms, style rules, and descriptions of how characters speak are kept in the project next to the translation and edited in the same place. Translators and agents follow them alike.

Patches

After a patch, the translation is carried over to the new version of the game, and lines the developers changed are marked for another review. When it cannot be determined with certainty which line a translation now belongs to, Aeria does not guess; the translation is set aside for review. No translation is lost.

Packs already installed by players keep working. Changed lines appear in the original language until an updated translation is published, and a translation is never applied to text it was not written for.

Working together

A project is an ordinary Git repository on GitHub or any other host; Git ships with Aeria. Saving and syncing cover everyday work, and branches and pull requests are available for larger teams. Every line keeps a history of its edits and their authors.

No account is required, and Aeria runs no servers of its own.

Harmonia

In the game, the translation is shown by Harmonia, a Dalamud plugin. Packs are published to GitHub Releases directly from Aeria. Installation for players:

  1. Launch the game through XIVLauncher with Dalamud enabled.
  2. Open /xlsettings → Experimental → Custom Plugin Repositories, add this address, and save:
    https://raw.githubusercontent.com/AngelicaProject/Harmonia/main/repo.json
  3. Open /xlplugins, install Harmonia, and restart the game.
  4. Open /harmonia, press Add translation, and paste the link from the translation's author or choose a downloaded .hpk file. Restart the game once more.

A translation added from a link updates automatically; changes take effect at the next game start. Cyrillic and other characters the game's fonts lack require Penumbra to appear in window titles and on the title screen.

Status

Aeria is at an early stage of development and changes quickly. A Windows version is available; a Linux version will follow. Bug reports and suggestions go to GitHub Issues, and pull requests are accepted.
