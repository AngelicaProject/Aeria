What it does

  • Opens the text straight from your game install, nothing to export.
  • Shows tags as hints like "if the character is female", and won't save a line with a broken tag.
  • Machine translation through a ChatGPT subscription fills a whole sheet in minutes. The model sees the Japanese original and the official localizations, not just the English, and the game's own names serve as its glossary.
  • Machine translation fills empty lines, and on request the lines a patch changed; every other translation stays as it is.
  • The project's style and the terms the game doesn't name are written down in the project, so the translation stays consistent from quest to quest.
  • Patches don't break the translation: Aeria moves it to the new game version and shows which lines changed.
  • Work as a team through a plain GitHub repository. Git is built in.

Installing a translation in the game

Players install the finished translation with the Harmonia plugin for Dalamud:

  1. Launch the game through XIVLauncher with Dalamud enabled.
  2. Open /xlsettings → Experimental → Custom Plugin Repositories, add this address, and save:
    https://raw.githubusercontent.com/AngelicaProject/Harmonia/main/repo.json
  3. Open /xlplugins, install Harmonia, and restart the game.
  4. Open /harmonia, press Add translation, and paste the link from the translation's author or choose a downloaded .hpk file. Restart the game once more.

A translation added from a link updates the next time the game starts. Cyrillic and other characters missing from the game's fonts need Penumbra to show in window titles and on the title screen.
