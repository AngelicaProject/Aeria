Translating with AI agents

Aeria works with Claude Code, Codex, and Hermes Agent, which connect from its settings. An agent reads a whole quest in the order the player sees it, and every line comes with the Japanese original and the three official localizations.

That helps most with names and jokes. The tavern 溺れた海豚亭, "the drowned dolphin", is the Drowning Wench in English, the Dauphin noyé in French, and Zur Ertränkten Sorge in German. An agent compares them, comes up with a name for its own language, and keeps using it across the project.

Big jobs get split among helper agents working in parallel. Finished lines show up in the editor right away, and anything a person wrote or approved stays as it is.

The game fills in numbers, names, and highlights through tags. Tags can move wherever a sentence needs them in Russian or Spanish, but if one gets lost or broken, Aeria won't save the line.

Editor

Instead of raw markup the editor says "if the character is female", and colored text shows in the game's own colors. Search runs across the whole game at once.

The project's terms, style notes, and descriptions of how each character talks sit next to the translation. Everyone translating uses them, agents included.

Game updates

After a patch, Aeria moves the translation to the new game version and marks the lines the developers changed. If a line changed so much that it's unclear where a translation belongs, it waits for review.

Packs players already have keep working. Changed lines just show in the original language until the next update.

Working together

A project is a regular Git repository, on GitHub or anywhere else. Git comes with Aeria, and on a normal day two buttons are enough, Save and Sync. Bigger teams can use branches and pull requests.

Every line shows who changed it and when. There's nothing to sign up for.

Harmonia

Harmonia, a Dalamud plugin, shows the translation in the game. Aeria can publish a pack to GitHub Releases on its own, and players install it like this:

  1. Launch the game through XIVLauncher with Dalamud enabled.
  2. Open /xlsettings → Experimental → Custom Plugin Repositories, add this address, and save:
    https://raw.githubusercontent.com/AngelicaProject/Harmonia/main/repo.json
  3. Open /xlplugins, install Harmonia, and restart the game.
  4. Open /harmonia, press Add translation, and paste the link from the translation's author or choose a downloaded .hpk file. Restart the game once more.

A translation added from a link updates the next time the game starts. Cyrillic and other characters missing from the game's fonts need Penumbra to show in window titles and on the title screen.

Development

Aeria is in early development. There's only a Windows version for now; Linux will come later. Bugs and ideas go to GitHub Issues, and pull requests are welcome.
