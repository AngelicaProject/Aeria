Aeria
GitHub Русский

An editor for fan translations of FINAL FANTASY XIV

Aeria takes the text from the installed game and exports a translation pack that players install with a plugin. The target language can be any language. Aeria is free and open source.

Download for Windows

Portable .zip Nightly build All releases

  • Aeria reads strings straight from the game files. Extracting them or keeping a copy in sync by hand is not needed.
  • Game tags, such as the player's name or a word that changes with the character's gender, show up as readable hints. A line with a broken tag cannot be saved.
  • Machine translation fills a whole sheet in one run. The model sees the Japanese original and the other official versions, and takes the names of items, places, and characters from the game itself.
  • When a patch changes a line, Aeria keeps the old translation and marks it for review.
  • Each project is an ordinary Git repository. Git comes bundled, and other translators send their changes as pull requests.

Players install translations with the Harmonia plugin.
