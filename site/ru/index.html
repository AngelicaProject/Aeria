Перевод FINAL FANTASY XIV на любой язык

Aeria берёт текст прямо из установленной игры и бережёт все игровые теги, пока вы переводите. Работать над переводом можно одному или всем сообществом, а выход патча не ломает ни проект, ни перевод, уже установленный у игроков.

Одна строка в трёх переводах

Оригинал
You obtain Value HighlightCompany Seals/Highlight.
Русский
Получено: Highlightпечати компании/Highlight × Value.
Испанский
Has obtenido Value Highlightsellos de compañía/Highlight.
Португальский
Você recebeu Value Highlightselos da companhia/Highlight.
Проверка
Все теги на месте во всех трёх переводах

Числа, имена и выделения игра подставляет в текст сама, с помощью тегов. Теги можно переставлять под грамматику своего языка, но строку, где тег потерян или повреждён, Aeria не сохранит.

Редактор

Вместо служебного кода редактор показывает теги понятными подсказками вроде «если персонаж — женщина», а цветной текст выводит нужным цветом. Тег из оригинала вставляется в перевод одним щелчком, ошибки подсвечиваются сразу. Искать можно по всему тексту игры.

Обновления игры

Патч не ломает перевод. Aeria сама переносит его на новую версию игры и помечает строки, которые изменили разработчики, чтобы их можно было перечитать. Если нельзя точно сказать, к какой строке теперь относится перевод, Aeria не угадывает, а откладывает его на проверку. Ни один перевод при этом не теряется.

Пак, уже установленный у игроков, тоже продолжает работать. Изменившиеся строки показываются на языке оригинала, пока автор не выпустит обновление, а к тексту, для которого перевод не писался, он не подставляется никогда.

Совместная работа

Над переводом может работать один человек или всё сообщество. Проект хранится в обычном Git-репозитории на GitHub или любом другом хостинге, а Git уже входит в Aeria. Для повседневной работы хватает сохранения и синхронизации, при необходимости есть ветки и пулл-реквесты. У каждой строки видна история правок.

Регистрация не нужна, своих серверов у Aeria нет.

Harmonia

Перевод в игре показывает Harmonia — плагин для Dalamud. Пак можно опубликовать в релизах GitHub прямо из Aeria, а игроки устанавливают его так:

  1. Запустите игру через XIVLauncher с включённым Dalamud.
  2. Откройте /xlsettings → Experimental → Custom Plugin Repositories, добавьте адрес репозитория и сохраните настройки:
    https://raw.githubusercontent.com/AngelicaProject/Harmonia/main/repo.json
  3. Откройте /xlplugins, установите Harmonia и перезапустите игру.
  4. Откройте окно плагина командой /harmonia, нажмите Add translation и вставьте ссылку от автора перевода или выберите скачанный файл .hpk. Перевод включится после следующего перезапуска игры.

Перевод, добавленный по ссылке, обновляется сам; изменения вступают в силу при следующем запуске игры. Для кириллицы в заголовках окон и на титульном экране нужен Penumbra.

Состояние разработки
