Редактор фанатских переводов FINAL FANTASY XIV

Aeria берёт текст из установленной игры и собирает из перевода пакет, который игроки ставят плагином. Язык перевода может быть любым. Программа бесплатная, код открыт.

Скачать для Windows

Portable .zip Ночная сборка Все релизы

  • Aeria читает строки прямо из файлов игры. Выгружать их и сверять копию вручную не приходится.
  • Игровые теги, например имя персонажа игрока или слово, которое меняется по его полу, видны как понятные подсказки. Строку со сломанным тегом сохранить нельзя.
  • Машинный перевод заполняет целый лист за один запуск. Модель видит японский оригинал и другие официальные версии, а названия предметов, мест и персонажей берёт из самой игры.
  • Если патч меняет строку, Aeria оставляет прежний перевод и помечает его для проверки.
  • Каждый проект — обычный Git-репозиторий. Git входит в комплект, а другие переводчики присылают правки через пул-реквесты.

Игроки ставят переводы плагином Harmonia.
